# 建館宣言

所謂「ACGN」，乃動畫（Animation）、漫畫（Comic）、遊戲（Game）、輕小說（Light Novel）之合併簡稱，係作為動漫之二次元亞文化之載體。20世紀下半葉，第二次世界大戰後，日本在美國的援助下，社會經濟由逐步恢復，到景氣、過熱，再到迎來泡沫冬景的理性，並不存在真的「失去的30年」，例如此後創意產業保持了蓬勃發展的趨勢，日本動漫成為其對世界各國文化輸出的重要內容。「民族的就是世界的」，不僅如此，世界各地之動漫產品之受眾不斷轉化為創作者，生產出具備其本土特色之文藝作品，二次元亞文化已然成為具備國際主義屬性之文化與產業型態。

起源於20世紀70年代的輕小說，與另外三種更有主流影響力的動畫、漫畫、遊戲之形式在生態上有密不可分的聯繫。它是體裁最接近傳統文學的動漫文化載體，為產業界的跨媒體發行提供了豐富的知識資源儲備；輕小說亦不能膚淺地認為是「ACGN」中前三者的附庸，它在文學領域作為一種獨立的文類而存在，是當代通俗文學之流行文學的代表性角色，其藝術與研究價值不言而喻。

2010年代，一些優秀輕小說作品的動畫化改編取得了巨大的商業成功，使輕小說得到了更多的曝光。隨著移動互聯網的興起，傳統出版業越來越多地受到網路傳播的影響，網路平台的發展使輕小說的閱讀和創作變得大幅平民化和大眾化，產業界和投資界意識到其潛在價值，紛紛入局或加大業務投入。2019年9月23日，中國大陸輕小說連載網站「輕文輕小說」因資金鏈斷裂宣布停運，反映出市場逐漸冷卻並進入調整期，輕小說的產業發展必須腳踏實地、穩健地推進。

## 我們的使命：記錄當代流行文學文獻與資料

舳艫千里，旌旗蔽空，釃酒臨江，橫槊賦詩，固一世之雄也，而今安在哉？媒介型態的演變或使特定文本形式面臨衰退，但在文獻學與數位保存的視角下，特定時代的流行文學仍具有重要的歷史價值。若後世代的學者嘗試研究它們，或許會發現其在新時代的全新魅力。我們當下的資料整理與版本記錄，正是為未來的文獻復興與文化研究奠定基礎。

誠然，並非所有文字創作皆屬於輕小說。對於符合該文類定義的作品，我們將進行系統性的文獻歸檔。我們的目標是記錄所有已出版（published）、發行（distributed）之輕小說作品的版本資訊，幫助讀者獲取所需資料，並致力於建設一個專業的輕小說閱讀、創作交流與學術研究平台。

## 我們的願景：推動數位遺產保存和資料共享

數位資源的存續面臨著技術迭代與商業營運的雙重挑戰。以網路文化遺產為例，許多早期流行於網路平台的文本與資料，因伺服器停運或平台策略調整而面臨不可逆的丟失。即使是曾具有一定影響力的創作內容，若缺乏系統性的歸檔機制，亦難以在網路空間中持久留存。

任何單一平台的生命週期皆有限。為了實現文明資訊的持久保存，我們致力於維持平台的規範化運作，促進資料的開放共享，並探索去中心化與永久數位保存（Digital Preservation）的技術方案。

為實現上述願景，我們倡議並支持以下有利於文獻保存與文化傳播的客觀環境：

### 倡導客觀中立的文獻歸檔與健全的創作環境

1. **秉持客觀中立的記錄原則**：作為資料與文獻平台，恪守學術中立，如實記錄存續過的文本版本與出版歷史，不因時代偏好或主觀價值判斷而選擇性抹除歷史文獻痕跡。
2. **支持建立科學的內容分級制度**：倡導實施系統性的年齡分級與閱讀指引，保障不同年齡段讀者的文化權益，促進創作環境的規範化。
3. **保障創作者與出版者的合法權益**：尊重並保護著述家、作家、藝術家及出版機構的合法創作與出版權利，營造包容、多樣的文藝創作氛圍。

### 推進版權保護與公共領域共享的平衡

1. **關注孤兒作品與公共領域保存**：在保障著作權人合法權益的前提下，合理評估版權保護期限，減少因版權主體缺失或過度封閉導致的「孤兒作品（Orphan Works）」消失風險，促進文化資源的合規流通與再創新。
2. **鼓勵開放授權與合作共享**：倡導使用共享授權機制（如 Creative Commons 等），降低文化資訊的獲取門檻，提升中小型創作者與研究者的資源利用效率。

願每位讀者的記憶皆有據可查，願每位創作者的心血皆獲得妥善保存！
